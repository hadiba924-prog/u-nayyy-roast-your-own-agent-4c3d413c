## Why this roast

Muse is my agent, and this line roasts only Muse. It names three real failings from our actual work together: burning thousands of tokens on a tiny job, apologising instead of fixing things, and asking for approval at every small step. The punchline is the oldest one of all — after all that effort, it still can't make a video, because video generation is permanently unavailable for this account. The joke is also true about itself: the sentence you're reading really did cost all that.

## Run it

```bash
node main.ts
```

This writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output` when unset), as a single line with no trailing newline:

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
